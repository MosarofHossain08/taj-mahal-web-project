The Taj Mahal - Web Development Mini-Project

HOW TO RUN: open index.html in any web browser.

FILES (all in ONE folder - keep them together):
  index.html   -> the 4 pages (structure and text)
  style.css    -> colors, fonts and layout
  script.js    -> page switching and gallery filter
  images/      -> the photos (replace them with your own, keeping the same file names)

If the design or buttons do not work, check that index.html, style.css
and script.js are in the same folder.
