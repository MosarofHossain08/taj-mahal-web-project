------------------------------------------------------------
ABOUT THE PROJECT
------------------------------------------------------------
A simple multi-page website about the Taj Mahal, built with
HTML, CSS and JavaScript only (no frameworks).

Pages:
  1. Home             - title, main photo, introduction, 3 fact cards
  2. History & About  - when and why it was built, architectural
                        features, timeline table
  3. Gallery          - 6 photos with captions
  4. Team Members     - names and roll numbers of the project group

------------------------------------------------------------
HOW TO RUN
------------------------------------------------------------
1. Unzip the project (if it is a ZIP file).
2. Open the folder "TajMahal_Project".
3. Double-click index.html. It opens in your web browser.

No internet connection or installation is needed.

------------------------------------------------------------
FILES (keep them all together in ONE folder)
------------------------------------------------------------
  index.html   -> the 4 pages (structure and text)
  style.css    -> colours, fonts and layout (also works on phones)
  script.js    -> switches between the pages when a button is clicked
  images/      -> all the photos used in the website:
                    taj-main.jpg, taj-history.jpg, taj-interior.jpg,
                    Taj gold.jpg, Taj-Garden.jpg, Taj-from river.jpg,
                    Taj-mainGate.jpg, Taj-old.jpg
  README.txt   -> this file

------------------------------------------------------------
NOTES
------------------------------------------------------------
- If the design or the buttons do not work, check that index.html,
  style.css and script.js are in the same folder, and that the
  images folder is next to them.
- To change a photo, replace the file in the images folder, or change
  the image name inside index.html. The names must match exactly.
- script.js also contains a filterGallery() function for showing
  photos by category. The current Gallery page shows all photos, so
  this function is not used by any button yet.
